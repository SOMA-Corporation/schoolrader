# 초등 종합분석 리포트 — 절 지도 작업설명서

참고자료가 아니라 작업 규칙서. 절 지도를 건너뛰고 바로 제작 시작 금지.

**이 문서는 초등학교(학교종류코드 02) 전용이다.** 공통 규칙은 `분석리포트_작업설명서.md` 에 있다 —
그 문서의 **§0 절대 규칙 · §4 틀 규격 · §8 빌드 파이프라인 · §9 원자료 함정**은 학교급과 무관하게 적용된다.
반대로 그 문서의 **§2 페이지 지도(21쪽)와 §3 자료 매핑은 고교 전용이다** — 초등에 들이대지 마라.
두 문서가 어긋나면 이 문서가 이긴다.

설계 근거와 실측은 `초중등_리포트_설계개요.md` 에 있다. 왜 이런 절 구성인지 궁금하면 그쪽을 본다.

만드는 것: 학원 내부용 초등학교 분석 리포트(표지~11절, 최대 20쪽).
독자는 학원 상담교사(표지 "내부용" 표기 유지). 각 절 말미 ▸ 분석 노트가 핵심 가치라는 규칙은 고교와 같다.

산출물: `분석리포트_{학교명 약칭}.pdf` 한 개 → `vault/{VAULT_ID}/out/`.

## 1. 초등은 무엇이 없고 무엇이 있나

### 1-1. 없는 것 — 만들지 마라

| 항목 | 사유 |
| --- | --- |
| 교과 성취도 분포(A~E) · 과목 평균 | **공시항목 4-나 가 초등에 없다.** 받지 못한 게 아니라 제도적으로 없다 |
| 석차 · 석차등급 · 등급컷 | 위와 같음. 초등 규정에 분할점수·석차 조항 자체가 없다 |
| 진학 중학교 | 초→중 배정은 어떤 공개 자료에도 없다. KESS 도 조사하지 않는다 |
| 학교 간 학업 성취 수준 비교 | 원자료가 없다 |

넷 다 표지 각주에 "다루지 않는다"고 밝힌다. **"일반적으로는…" 으로 채우는 것은 공통 규칙 §0-7 위반이다.**

### 1-2. 있는 것 — 고교 템플릿이 안 쓰던 자료

실측 결과 초등은 고교 45개 공시항목 중 40개를 그대로 공유한다. 잃는 것은 성적 하나뿐이고,
고교 리포트가 안 쓰던 자료가 초등에는 그대로 있다.

| 축 | 자료 | 절 |
| --- | --- | --- |
| **유입과 유출** | 3-나 전·출입 3개년(학년별 + 구/시도/전국 비교) | **02 — 리포트의 무게중심** |
| **지역 벤치마크** | 초등 공시표에는 거의 전부 구/시도/전국 비교행이 붙는다 | 전 절 |
| **학년별 교과평가계획** | 4-가 첨부 — 학년별로 파일이 쪼개져 있다 | 04 |
| **체력 등급 분포** | 15-자 PAPS — 학년×성별×1~5등급 + 지역비교 | 06 |
| **방과후·돌봄** | 15-라 + apiType 59(ECC) | 07 |

**02절이 고교에서 성취도 분포가 있던 자리다.** 분량과 공을 거기에 쓴다.
"이 학교 학군에 수요가 얼마나 있고, 언제 들어오고, 학교가 아이를 몇 시까지 잡아두는가" —
이게 초등 리포트가 답하는 질문이다.

## 4. 초등 전용 원자료 함정

공통 규칙 §9 의 함정(매직바이트 · 파일명 연도 vs 시트 연도)은 그대로 적용된다. 아래는 초등에서 새로 확인한 것.

### 4-1. 학생수 기준이 두 개다

같은 공시 안에서 두 숫자가 돈다.

- **{공시연도}.4.1 재학생** — apiType 09·62·63. 급식·도서관·동아리 1인당 계산의 분모
- **직전 4.1 학생수** — 3-나 전출입 표의 분모, 도서관 대출 통계의 분모

한 해에 10% 가까이 줄어드는 학교도 있다. 두 값을 섞으면 비율이 전부 어긋난다.
**모든 1인당·비율 지표는 분모를 표에 함께 적는다.**

### 4-2. 교원 수가 세 가지다

| 값 | 출처 | 정의 |
| --- | --- | --- |
| 수업교원 | apiType 08 · 09(`TEACH_CNT`) | 수업을 맡는 교원 |
| 전체 교원 | apiType 22 직위별 총계 | 교장·교감·보건·영양·기간제 포함 |
| KESS 교원수 | `kess-es.json` `tch` | 전체 교원, 조사기준일이 다르다 |

"교원 1인당 학생수"도 분모에 따라 달라진다. **표지에 어느 기준인지 밝히고 전 문서에서 하나로 통일한다.**

### 4-3. PAPS 커버리지

- **초1~3 은 측정 대상이 아니다.** 06절은 4·5·6학년만이다
- 연도마다 실린 학년이 다르다. 4학년이 아예 없는 해, 검사 인원이 한 자릿수인 해가 있다
- 그래서 **3개년 막대가 온전히 서는 학년은 대개 5·6학년뿐이다.** 4학년은 최신 1개년만 싣고
  각주에 사유를 적는다. 없는 해의 `.yline` 은 막대 없이 `–` 만 둔다(공통 규칙 §4-2 와 같다)
- 검사 인원수를 각 줄에 함께 적는다 — 인원이 한 자릿수인 해를 분포로 읽으면 안 된다
- 종목 표는 머리글이 12종인데 실제로 값이 든 칸은 5개 안팎이다.
  **열 위치로 읽지 말고 머리글로 매칭하고, 빈 종목은 열에서 뺀다**

### 4-4. 비율은 대부분 산출치다

공시는 학교의 비율을 직접 주지 않고 **지역 비율만** 준다(전입률·전출률·참여율 등).
학교 값은 인원과 분모에서 직접 나눠야 한다. 산출한 값에는 산출 방법을 각주에 반드시 밝힌다.

### 4-5. KESS 연도 라벨

`kess-es.json` 의 연도 키는 조사연도(4/1)이고, 그 행의 **전입·전출은 직전 학년도** 값이다.
학교알리미 표와 나란히 놓을 때 연도를 학년도로 통일하고 기준일을 표 부제에 적는다.

### 4-6. 입학자 ≠ 4/1 재학생

`kess-es.json` 의 `enter`(입학자)와 `g1`(1학년 4/1 재학생)이 다르다 —
그 사이에 이미 전입이 들어왔기 때문이다. 두 값을 섞지 마라.

## 5. 06절 — `.ach` 를 1~5등급에 재사용하는 규칙

공통 규칙 §4-2 의 `.ach` 5열 구조를 그대로 쓴다. 열은 다섯으로 고정이다.

```
분류(7%) | 구분(14%) | 성별(6.5%) | 3개년 분포(53.5%) | 판정·분석(19%)
```

- 세그먼트 클래스는 `.sA`~`.sE` **그대로 둔다.** 범례 라벨만 `1등급`~`5등급` 으로 바꾼다.
  클래스 이름을 바꾸면 `<style>` 을 건드려야 하고, 그 순간 세 학교급의 렌더가 갈라진다
- `.ann` 에는 `1등급 {%} · n {검사인원}` 을 적는다
- 판정 라벨은 **지역 비교로 쓴다** — 등급별 비율의 구/시도/전국 비교행이 같은 표에 있다.
  예: `1등급 구 평균 밑` · `4·5등급 두께 구 대비 큼` · `3년 내리 개선` · `n 부족 — 판정 보류`

## 6. 분석 노트가 답해야 할 질문

절마다 `▸ 분석 노트`가 데이터 재진술이 아니라 **실무 결론**이어야 한다는 규칙은 고교와 같다.

| 절 | 답할 것 |
| --- | --- |
| 01 | 어느 학년이 두꺼운가. 학급당 인원이 구 평균 대비 어떤가. 학년별 반을 몇 개로 열 것인가 |
| 02 | 신규가 언제 들어오는가. 유입이 늘고 있는가 꺾이는가. 어느 학년에 마케팅을 걸 것인가 |
| 03 | 신입생 규모가 몇 년째 어떻게 변했는가. 저학년 시장이 유지되는가 |
| 04 | 학교가 무엇을 언제 어떤 방식으로 평가하는가. 학원 진도를 어디에 맞출 것인가 |
| 05 | 학교가 몇 시에 끝나는가. 수준별 수업이 있는가 |
| 06 | 체력·비만 분포가 구 대비 어떤가. 체육 연계 상품 여지 |
| 07 | 방과후·돌봄이 몇 명을 몇 시까지 잡아두는가. 우리 수업을 몇 시에 열 것인가 |
| 09 | 구 평균에 견줘 두드러지게 낮거나 높은 지표. 그 자리에 학원이 채울 수 있는 것 |
| 11 | 학부모 상담에서 이 학교에 대해 답해 줄 수 있는 것 |

## 7. 검수 — 초등 추가 항목

공통 규칙 §8-4 의 (가) 구조 대조와 (나) 내용 검수를 **둘 다** 돌린 뒤, 아래를 더 본다.

- 생성 PDF 쪽수 vs §2 지도(20쪽) — 뺀 절만큼만 줄었는가
- `.ach` 표가 5열을 유지하는가
- **`{{` 로 시작하는 자리표시자가 한 개도 남지 않았는가**
- **`<!-- ■ 채우기` 주석이 한 개도 남지 않았는가**
- **성취도·석차·등급컷·진학 중학교를 만들지 않았는가** — 텍스트에서 `성취도` `석차` `등급컷` 검색
- 모든 1인당·비율 지표에 분모가 적혀 있는가 (§4-1)
- 모든 산출치에 산출 방법이 각주에 있는가 (§4-4)
- 교원 수 기준이 전 문서에서 하나인가 (§4-2)
- 학교명·연도가 전 페이지 일치하는가
