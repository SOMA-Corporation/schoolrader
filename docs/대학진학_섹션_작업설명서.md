# 대학진학 섹션(08절) — 에이전트 작업 설명서

학교분석 리포트 PDF 뒤에 **대학진학 장표 2~3장을 같은 디자인으로 생성·병합**하는 작업 지시서.
입력: `학교명` + 기존 리포트 PDF 경로. 출력: 진학 섹션이 붙은 병합 PDF.

> 사용법: 이 파일을 Claude Code에게 주고 다음 한 줄만 지시한다.
> **"이 설명서대로 `OO고등학교` 대학진학 섹션을 만들어서 `리포트.pdf` 뒤에 붙여줘."**

---

## 0. 절대 규칙 (톤)

이 리포트의 독자는 **입시학원 원장**이다. 완성 장표에는:

- ❌ 데이터를 "어디서 어떻게 구했는지"에 대한 서술 금지 (공시가 없다느니, API로 검증했다느니, 수집 과정 이야기 전부 금지)
- ❌ "출처 등급", "신뢰도" 같은 메타 분류 노출 금지
- ✅ 모든 문장은 **"이 학교가 어떤 학교인가 → 학원 상담·상품에 어떻게 쓰나"** 관점
- ✅ 각 장표는 반드시 `▸ 분석 노트`로 끝난다 — 수치 요약이 아니라 **실무 행동 지침** 2~3개 (상담 화법, 개입 시점, 상품 설계)
- ✅ 출처는 페이지 하단 7pt 한 줄만. 단, 표 안에 **"중복 합격 포함" / "인원 기준"** 구분과 **"합격 ≠ 등록"** 각주는 필수 (상담 사고 방지용이므로 이건 메타가 아니라 실무 정보다)
- ✅ 기존 리포트의 다른 절(성취도 06절, 동아리 07절 등)이 있으면 분석 노트에서 교차 참조할 것

## 1. 데이터 수집

### 1-A. 학교별 진로 현황 (필수) — KESS 교육통계서비스

고교별 진학·재수 데이터의 원천. ⚠️ 학교알리미 웹/NEIS API에는 고교 진학 통계가 없으므로 시도하지 말 것.

1. `https://kess.kedi.re.kr/contents/dataset` 접속 (브라우저 도구 또는 curl)
2. **"학교별(상반기)"** 최신 3개년 연도 링크에서 `downLoad('ID','파일명.xlsx',...)` 파라미터 추출
3. 직접 다운로드: `https://kess.kedi.re.kr/contents/dataSet/downLoad.do?fileNm={파일명}&userfileNm=data.xlsx` (인증 불필요, 각 ~18MB)
4. 파일명 예 (2026.2 시점): 2025년=`2026162291710.xlsx`, 2024년=`202511821729896.xlsx`, 2023년=`202511821715160.xlsx` — 갱신되므로 반드시 페이지에서 새로 확인

**엑셀 구조** (시트 `학교별 주요통계`):
- 헤더: 14~16행(0-index) 3단 구성, 데이터는 `skiprows=17`
- 주요 컬럼 (0-index, **연도별로 밀릴 수 있으니 헤더 텍스트로 재탐색할 것**):
  `1`시도 `2`행정구 `4`학교급 `5`고교유형 `8`학교명 `115`졸업자_계 `118`진학자_계 `121`진학률 `122`취업자_계 `125`입대자_계 `127`기타_계 `130`국내전문대_계 `133`국내대학_계 `136`국외전문대_계 `139`국외대학_계
- 조사기준 4/1 → "졸업 후 상황"은 **직전 2월 졸업생** 기준. 장표에는 "2025. 2." 형식으로 표기

**추출 대상**:
- 대상 학교 3개년: 졸업자·진학자(4년제/전문대/국외)·진학률·취업·입대·기타
- 비교군 4~5곳: 같은 행정구의 유사 학교 (일반고·자율고 위주, 학교알리미 학교 페이지의 '추천 연관 학교' 참고 가능)
- 집계 3종: 해당 행정구 / 해당 시도 / 전국 — **일반고+자율고만 합산** (특목·특성화 제외, 이 기준을 출처 줄에 명시)

**검산 (필수)**: ① 진학+취업+입대+기타 = 졸업자 ② 진학률 셀이 0.0이면 미기재이므로 재계산(진학자÷졸업자)하고 범례에 "재계산치" 표기 ③ 과거 연도 파일은 일부 학교 미기재 가능 — 0이면 해당 연도 집계에서 제외

**핵심 파생 지표**: `기타율 = 기타 ÷ 졸업자`. 취업·입대가 0에 가까우면 **기타 ≈ N수(재수) 규모**로 해석 — 이 리포트의 중심 스토리.

### 1-B. 대학별 실적 (선택) — 웹 검색

찾으면 3페이지째를 만들고, 못 찾으면 2장으로 마무리한다.

- 검색어: `"{학교명}" 서울대 합격 {연도} 고교별`, `"{학교명}" 의대 합격자 수 {연도}` (국정감사 자료 기반 언론 보도 — 베리타스알파 「서울대 실적」 시리즈 등)
- 수집: 서울대 최종 합격(수시/정시, 재학/졸업생 구분), 서울대 의대, 의약학 계열 합격 건수(학원가 집계)
- ⚠️ 의약학 '건수'는 **중복 합격 포함** — 표 비고에 반드시 표기, 인원으로 읽지 않게 할 것
- ⚠️ 수치는 반드시 기사 원문에서 확인. 커뮤니티 재유통 수치는 원출처가 확인될 때만 사용
- 서울대 합격 중 N수 비중(졸업생 수 ÷ 합격 수)을 계산해 1-A의 재수율과 교차 서사로 연결

### 1-C. (선택) 학교 기본정보 검증

`https://open.neis.go.kr/hub/schoolInfo?SCHUL_NM={학교명}&Type=json` (무키 가능) — 동명 학교 구분·주소 확인용. 결과는 내부 확인만 하고 장표에 쓰지 않는다.

## 2. 장표 구성 (2~3장)

### 페이지 A — "08 대학진학 — 졸업생 진로 현황" (필수)
- 도입 1~2문장: 이 학교 진로 구조의 한 줄 정의 (예: "졸업생 2명 중 1명이 재수를 선택하는 학교다")
- 스탯 카드 5개: 졸업자 / 대학 진학(명·%) / 기타(명·%, 적색) / 진학 중 4년제 비중 / 취업·입대
- 3개년 표: 졸업 | 졸업자 | 진학 계(4년제/전문대) | 진학률 | 취업 | 기타 | 기타율 | 누적 막대그래프 (최신년 행 하이라이트)
- 분석 노트: ① 기타≈N수 해석과 상담 출발점 ② 4년제 집중 여부 ③ 기존 리포트 성취도 절과의 연결 (해당 학교 데이터에 맞게)

### 페이지 B — "08 대학진학 — 지역·경쟁교 비교 (계속)" (필수)
- 비교 표: 대상 학교(하이라이트) + 경쟁교 4곳 + 행정구 평균 + 시도 평균 + 전국 평균 — 졸업자/진학/진학률/기타율 + 기타율 막대
- 가로 막대 4줄: 학교 → 구 평균 → 시도 평균 → 전국 평균 기타율 낙차
- 분석 노트: ① 재수가 학교 현상인지 지역 구조인지 판정 ② 경쟁교 대비 포지셔닝 ③ 상품 설계 연결

### 페이지 C — "08 대학진학 — 어느 대학으로 (계속)" (1-B 성공 시)
- 도입: 진학의 질로 본 학교 좌표 (최상위 실적 한 줄)
- 스탯 카드 4개: 서울대 합격 / 서울대 의대 / 의약학 합격(중복) / 서울대 합격 중 N수 %
- 실적 표: 학년도 | 구분 | 수치·내용 | 비고(인원 기준/중복 합격 포함) + "합격 ≠ 등록" 각주
- "상담 도구 — 내신 등급별 지원권 밴드" 3단계 카드: ① 어디가(adiga.kr) 등급 70%컷 확보 → ② 학교 내신 환산표와 매핑("내신 X등급 = 이 대학 밴드") → ③ 재학 밴드/재수 포함 밴드 분리 제시 (3번 카드는 다크 스타일)
- 분석 노트: 재수율·N수 비중·중복 합격이 가리키는 하나의 결론 + 상담 기준 화법 + 파이프라인 상품 설계 + 자료 갱신 시점(11월 설명회)

## 3. 디자인 스펙 (원본 리포트 복제)

⚠️ 시작 전에 원본 PDF 2~3장을 이미지로 렌더링해(PyMuPDF) 아래 값과 실제 스타일이 일치하는지 눈으로 확인할 것. 다른 템플릿의 리포트라면 색·구성요소를 다시 샘플링해서 아래 CSS를 수정한다.

**토큰**: 배경 `#fbfbfb` · 마룬(강조) `#7c212f` · 본문 `#16181f` · 회색 `#898577` · 표 헤더 `#dcdad3` · 라벨 셀 `#e9e7e0` · 노트 박스 `#f5eff0` · 막대: 진학 `#2b4972` / 취업 `#dba05e` / 기타 `#a83126` · 적색 강조 `#a83126` · 청색 강조 `#2b4972` · 폰트 Noto Sans KR (Google Fonts)

**구성요소**: 섹션 헤더(마룬 "08" + 볼드 제목 + 우측 영문 letterspacing 라벨 + 하단 1.6pt 검정 룰) · 스탯 카드(흰 배경, 상단 2.4pt 마룬 보더) · 표(0.5pt 보더, 최신/대상 행 `#f5eff0` 하이라이트) · 분석 노트(`▸ 분석 노트` 마룬 라벨 + 좌측 3pt 마룬 바 박스) · 출처(상단 얇은 룰 + 7.3pt 회색)

**HTML 골격** (A4, 페이지당 `<div class="page">`):

```css
@page { size: A4; margin: 0; }
body { font-family:'Noto Sans KR','Malgun Gothic',sans-serif; color:#16181f; background:#fbfbfb; }
.page { width:210mm; height:296mm; padding:14mm 15mm 12mm; page-break-after:always; overflow:hidden; }
.sechead { display:flex; align-items:baseline; border-bottom:1.6pt solid #16181f; padding-bottom:8pt; }
.sechead .num { color:#7c212f; font-weight:900; font-size:17pt; margin-right:6pt; }
.sechead .tit { font-weight:900; font-size:15.5pt; white-space:nowrap; }
.sechead .eng { margin-left:auto; font-size:8.5pt; color:#aeaeb1; letter-spacing:2.5pt; font-weight:700; }
.card { flex:1; background:#fff; border:0.6pt solid #cfccc4; border-top:2.4pt solid #7c212f; padding:6pt 8pt; }
.note { background:#f5eff0; border-left:3pt solid #7c212f; padding:8pt 10pt; font-size:8.8pt; line-height:1.62; }
```

(표·막대·스텝 카드 등 나머지는 위 토큰에 맞춰 작성. 제목·카드 텍스트는 `white-space:nowrap` 또는 짧은 문구로 **줄바꿈 방지**.)

## 4. 빌드 파이프라인

1. **HTML 작성** → 스크래치 폴더에 `pages.html`
2. **PDF 변환** (Edge 헤드리스, Windows):
   ```
   msedge --headless=new --disable-gpu --no-pdf-header-footer --virtual-time-budget=15000 --print-to-pdf="new_pages.pdf" "file:///.../pages.html"
   ```
   (macOS/Linux는 Chrome 동일 플래그. 웹폰트 로딩을 위해 virtual-time-budget 필수)
3. **병합** (pypdf): 원본 PDF 전체 + 새 페이지들 → `{원본이름}_진학추가.pdf`. **원본 파일은 절대 덮어쓰지 않는다.** 대상 경로가 잠겨 있으면(PermissionError) `_v2` 접미사로 저장
4. **QA (필수)**:
   - PyMuPDF로 병합본의 새 페이지 + 직전 원본 페이지를 렌더링해 나란히 눈으로 비교 (톤·여백·폰트 이질감)
   - 체크: 제목/카드 텍스트 줄바꿈·잘림 없음 / 표가 페이지 안에 들어옴 / 막대 % 합계 100 / 하이라이트 행 위치
   - 수치 재검산: 표의 모든 비율을 원데이터로 다시 나눠 확인
   - 문제 발견 시 HTML 수정 → 2번부터 반복

## 5. 실패 대응

| 상황 | 대응 |
|---|---|
| KESS 다운로드 링크 변경 | 페이지에서 `downLoad(` onclick 파라미터를 다시 긁는다 |
| 컬럼 인덱스 불일치 | 헤더 3단(14~16행)에서 `졸업자_계`, `진학자_계` 등 텍스트로 위치 재탐색 |
| 과거 연도 학교 데이터 0 | 그 연도는 학교 표에서 제외하거나 각주 처리, 집계 평균에서도 제외 |
| 대학별 실적 보도 없음 | 페이지 C 생략, 2장으로 완성 (억지로 채우지 않는다) |
| 특성화고/직업계고 대상 | '기타≈N수' 해석 불가 — 취업률 중심으로 스토리 전환 (취업자·산업체 진학 축으로 재구성) |
| 원본 디자인이 다른 템플릿 | §3 시작의 샘플링 절차로 색·폰트 재추출 후 CSS 교체 |
