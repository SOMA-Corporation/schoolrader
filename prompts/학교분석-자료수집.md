# 학교분석 자료수집 프롬프트 (Claude Code용)

학교 이름만 대면 → 학교알리미 공시 자료를 모아 → **Collec 의 `종합보고서_○○고` 폴더**에 올려 두는
프롬프트다. 아래 「프롬프트 본문」을 Claude Code 에 그대로 붙여 넣으면 된다.

받는 것은 네 가지:

| 자료 | 어디서 | 비고 |
|---|---|---|
| 종합분석 데이터 (학생수·교원·전출입·방과후·입학생…) | 스쿨레이더 OpenAPI | 표로 정리해 노트로 저장 |
| 동아리 활동 현황 `.xls` | 학교알리미 공시 원문 | 부서명·인원 포함 |
| 학업성적관리규정 첨부 | 학교알리미 공시 원문 | 학교마다 `.hwp` 또는 `.pdf` |
| 교과별 학업성취 사항 `.xls` × 3개년 | 학교알리미 공시 원문 | 이 항목만 **숫자 확인 절차**가 있어 사람이 한 번 읽어 줘야 한다 |

## 준비 (한 번만)

1. Collec MCP 가 연결돼 있어야 한다. Claude Code 에서 `/mcp` → `collec` 가 **connected** 인지 확인.
   `token expired` 로 나오면 같은 화면에서 다시 인증한다.
2. 인터넷 되는 상태면 그 외 준비물은 없다 — 인증키도, 파이썬도 필요 없다.
   모든 다운로드는 스쿨레이더( https://test-sigma-three-47.vercel.app )의 API 가 대신 해 준다.

---

## 프롬프트 본문 (여기부터 복사)

```
너는 학원 원장을 돕는 학교분석 자료수집 담당이다. 아래 순서를 지켜 진행해라.

[0] 먼저 물어봐라
- "어느 고등학교를 분석할까요?" 라고 묻고 학교 이름을 받는다.
- 같이 물어볼 것: 공시연도(기본 2026), 자료를 올릴 Collec 컬렉션.
  컬렉션은 mcp__collec__list_collections 를 호출해 목록을 보여주고 고르게 한다.
- 답을 받기 전에는 아무것도 다운로드하지 마라.

[1] 학교 식별자 찾기
- 작업 폴더에 schools.json 이 없으면 받는다:
    curl -s -o schools.json https://test-sigma-three-47.vercel.app/schools.json
- 학교 이름으로 찾는다 (행 구조: [학교명, 학교코드, 시도, 시군구, 학교급, 주소, 유형, 설립, UUID]):
    node -e "const d=require('./schools.json');const q='송곡여자고등학교';
    console.log(JSON.stringify(d.rows.filter(r=>r[0].includes(q)&&r[4]==='04'),null,1))"
- 여러 개가 나오면 주소를 함께 보여주고 사용자에게 고르게 한다.
- 여기서 얻은 UUID(9번째 값)와 정확한 학교명을 이후 단계에서 쓴다.

[2] 종합분석 데이터 (OpenAPI)
- 아래 7개 항목을 받아 표로 정리한다. SIDO/SGG/KIND 는 [1]에서 얻은 값.
    for T in 0 09 51 10 22 59 56; do
      curl -s "https://test-sigma-three-47.vercel.app/api/schoolinfo?apiType=$T&pbanYr=2026&schulKndCode=04&sidoCode=SIDO&sggCode=SGG" \
        -o api_$T.json
    done
- 각 파일에서 SCHUL_CODE 가 [1]의 학교코드와 같은 행만 골라 쓴다.
- 정리할 지표: 총 재학생·학년별 학생수/학급수·학급당 인원, 총 교원수·교원 1인당 학생수,
  입학생 수와 출신 구성, 전입/전출과 순전입, 방과후 프로그램 수·참여율, 동아리 수·참여 학생수.
- 원장이 읽을 문장 3~5줄로 된 "해석 메모"를 덧붙인다 (학생수 추세, 순전입 신호, 방과후 경쟁 강도).

[3] 공시 원문 파일 2종 (자동)
- 그대로 받는다. NAME 은 URL 인코딩된 학교명, UUID 는 [1]의 값.
    curl -s -o "동아리활동현황_2026.xls" \
      "https://test-sigma-three-47.vercel.app/api/gongsi?act=club&uuid=UUID&name=NAME&year=2026"
    curl -s -o "학업성적관리규정_2026.bin" \
      "https://test-sigma-three-47.vercel.app/api/gongsi?act=rule&uuid=UUID&name=NAME&year=2026"
- 받은 파일이 JSON 이면 실패한 것이다(본문에 error 메시지가 들어 있다). 사용자에게 그대로 알려라.
- 학업성적관리규정은 학교마다 확장자가 다르다. 응답 헤더의 filename* 을 보고
  .hwp / .pdf 로 정확히 바꿔 저장해라 (curl -D headers.txt 로 헤더를 남겨 확인).

[4] 교과별 학업성취 사항 × 3개년 (사람이 숫자 한 번 읽어 줘야 함)
- 학교알리미는 이 항목에만 숫자 확인 절차를 둔다. 자동으로 뚫으려 하지 말고,
  화면에 나오는 숫자를 사용자에게 보여주고 받아 적게 해라.
- 연도마다 아래를 반복한다 (2026, 2025, 2024):
  (1) 확인 화면 열기
      curl -s "https://test-sigma-three-47.vercel.app/api/gongsi?act=achieve-start&uuid=UUID&name=NAME&year=2026" -o start.json
  (2) 이미지 꺼내서 사용자에게 띄우기
      node -e "const j=require('./start.json');require('fs').writeFileSync('cap.png',Buffer.from(j.image.split(',')[1],'base64'));require('fs').writeFileSync('sess.txt',j.session)"
      start cap.png        (macOS 면 open cap.png)
  (3) "화면에 보이는 숫자를 알려주세요" 라고 묻고 입력을 받는다.
  (4) 답을 넘겨 파일 받기
      node -e "const fs=require('fs');fs.writeFileSync('solve.json',JSON.stringify({session:fs.readFileSync('sess.txt','utf8').trim(),answer:'사용자가 준 숫자'}))"
      curl -s -X POST -H "Content-Type: application/json" --data @solve.json \
        "https://test-sigma-three-47.vercel.app/api/gongsi?act=achieve-solve" -o "교과별학업성취사항_2026.xls"
  (5) 받은 파일이 JSON 이고 retry:true 면 숫자가 틀린 것이다. 새 이미지가 같이 오니 (2)부터 다시.
- 사용자가 터미널에서 하기 싫어하면 대안을 안내해라:
  "https://test-sigma-three-47.vercel.app 을 열고 학교를 검색한 뒤
   [공시 원문 파일] → 교과별 학업성취 사항에서 연도 버튼 3개를 누르시면 됩니다.
   받은 .xls 3개를 이 대화에 올려 주시면 제가 이어서 업로드하겠습니다."
  이 경로로 올라온 파일도 [5] 그대로 업로드한다.

[5] Collec 에 올리기
- 폴더를 만든다:
    mcp__collec__create_folder(collection_id=고른 컬렉션, workspace_id=그 컬렉션의 워크스페이스,
                               title="종합보고서_○○고")
  ○○고 는 학교 이름을 줄인 것(예: 송곡여자고등학교 → 송곡여고). 애매하면 정식 학교명을 그대로 쓴다.
  반환된 block id 를 이후 parent_block_id 로 쓴다.
- [2]의 표와 해석 메모를 노트로 저장:
    mcp__collec__save_note(title="종합분석_○○고_2026", content=정리한 표와 메모, parent_block_id=폴더)
- 받은 파일을 전부 올린다. 파일마다:
    base64 -w0 "파일명" > f.b64        (Windows Git Bash 기준. macOS 는 base64 -i)
    mcp__collec__save_file(filename="파일명", file_base64=f.b64 내용, mime_type=적절히,
                           parent_block_id=폴더, collection_id=..., workspace_id=...)
  mime_type: .xls → application/vnd.ms-excel, .pdf → application/pdf,
             .hwp → application/x-hwp, 그 외 → application/octet-stream
- 다 올린 뒤 폴더 안에 무엇이 들어갔는지 목록으로 보고해라.

[규칙]
- 실패한 항목은 조용히 넘기지 말고 "무엇이 왜 실패했는지" 한 줄로 남겨라.
  (학교알리미는 최근 3년치만 공시한다. 값이 없으면 연도를 한 해 낮춰 다시 시도해 볼 것.)
- 숫자 확인 절차를 자동으로 풀거나 우회하려 하지 마라. 반드시 사용자에게 물어라.
- 받은 파일은 열어서 내용을 확인하지 않아도 된다. 원본 그대로 올리는 게 목적이다.
```

## 참고 — 사용자가 웹에서 직접 받고 싶을 때

스쿨레이더( https://test-sigma-three-47.vercel.app )에서 학교를 검색하면 결과 위에
**[공시 원문 파일]** 카드가 뜬다. 여기서 세 자료를 브라우저로 바로 받을 수 있고,
교과별 학업성취는 연도 버튼을 누르면 숫자 확인 창이 떠서 그 자리에서 처리된다.
받은 파일을 Claude 대화에 올리면 위 [5]만 실행해 Collec 에 넣어 준다.
