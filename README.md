# 스쿨레이더 (SchoolRadar) — 학교분석보고서 데이터 추출기

학원 원장이 URL 하나만 열면 학교별 공시 데이터를 표로 받아가는 페이지.
**인증키를 요구하지 않고**(키는 서버에만 있다), **지역도 고르지 않는다** —
학교 이름만 치면 전국 12,650개교에서 자동완성으로 골라 바로 조회된다.

## 구조

```

public/app.html      도구 — 학교 검색 · 공시 원문 파일 · 결과 표 · 리포트 만들기
public/vault.html    저장소 — 받아 둔 자료와 만들어진 리포트를 폴더 그대로 본다
public/style.css     세 페이지가 같이 쓰는 스타일
public/gate.js       접속 코드 상수 — 페이지들이 같은 값을 봐야 해서 따로 뒀다
public/schools.json  전국 학교 색인 — 이름 검색용. build-schools.js 가 만든다
public/kess.json     고교 진로·규모 색인 — build-kess.js 가 만든다
public/kess-ms.json  중학교 색인 (진학률·규모)      〃
public/kess-es.json  초등학교 색인 (학년별 규모 4개년) 〃
public/favicon.svg   레이더 마크. favicon-32.png · apple-touch-icon.png 는 SVG 를 못 받는 브라우저용
api/schoolinfo.js    학교알리미 OpenAPI 중계
api/gongsi.js        공시 원문 파일 받아오기 — OpenAPI 에 없는 자료
api/vault.js         저장소 읽기·쓰기          ← 로컬 전용(디스크에 쓴다)
api/report.js        리포트 생성 — 클로드코드 실행 ← 로컬 전용(프로세스를 띄운다)
vault/               ★ 받은 자료와 만들어진 리포트. 웹과 에이전트가 만나는 지점
docs/                작업설명서(공통 + 초·중) · 틀 정본 3종 · 설계개요 · 예시
prompts/             Claude Code 프롬프트 (자료수집 · 리포트 생성 초/중/고)
build-schools.js     색인 생성기 (1년에 한 번만 돌리면 된다)
build-kess.js        진로·규모 색인 생성기 (1년에 한 번)
regions.json         시도·시군구 코드표 — 색인 만들 때만 쓴다
dev.js               서버. 정적 서빙 + api/* + vault/ 파일 서빙 + .env 로드
.env                 선택값 덮어쓰기용 (없어도 된다). 인증키는 api/schoolinfo.js 에 있다
vercel.json          함수 타임아웃 설정 — 지금은 쓰지 않는다(아래 「로컬 전용」)
```

## 로컬 전용이다

`node dev.js` 로 띄워 쓴다. **배포하지 않는다.**

받은 파일을 브라우저가 아니라 프로젝트 폴더에 쌓고, 그 폴더에서 클로드코드가 리포트를
만들고, 만든 PDF 를 다시 웹이 보여 주는 구조이기 때문이다. 이 셋은 전부 디스크에 쓰거나
프로세스를 띄우는 일이라 Vercel 서버리스에서는 **원리적으로** 안 된다 — 서버리스 함수의
파일시스템은 읽기 전용이고, `/tmp` 마저 호출 사이에 유지되지 않는다.

```bash
node dev.js        # http://localhost:3000
```

`api/schoolinfo.js` · `api/gongsi.js` 는 그대로 서버리스 형태를 지키고
있어서, 저장소·리포트 기능을 뺀 조회 전용으로는 언제든 다시 배포할 수 있다.

## 저장소 (`vault/`)

웹이 쓰고 클로드코드가 읽는 **하나의 폴더**다. 전에는 IndexedDB 였는데, 브라우저 안에만
있어서 에이전트가 못 읽고, 기기를 옮기면 사라지고, 200MB 상한에 걸리면 오래된 것부터
버려야 했다. 그 세 가지가 한 번에 없어진다.

```
vault/{학교명}_{공시연도}/
  raw/        공시 원문 — 동아리 .xls · 학업성적관리규정 · 교육과정 편제 · 성취도 3개년
  data/       openapi.json (조회한 7개 항목 그대로) · 졸업생진로_….csv (KESS)
  out/        분석리포트_○○고.pdf · 제작메모.md   ← 클로드코드가 넣는다
  meta.json   학교 식별자(코드·UUID·지역) · 파일 목록 · 리포트 상태
```

- **학교를 조회하면** 화면에 띄운 그 값이 `data/openapi.json` 에 함께 저장된다 —
  리포트를 만들 때 API 를 다시 부르지 않아도 된다.
- **「받음」이 아니라 「저장됨」** — 체크박스 오른쪽 표시는 브라우저 기록이 아니라 실제 폴더를
  보고 켜진다. 다른 브라우저로 열어도, 방문 기록을 지워도 그대로다.
- 서버는 `meta.json` 을 믿지 않고 **폴더를 다시 훑는다**. 그래서 클로드코드가 `out/` 에
  PDF 를 넣거나 탐색기에서 파일을 지워도 새로고침만으로 화면에 반영된다.
- 파일명은 학교가 올린 원본 이름을 그대로 쓴다(경로 구분자와 윈도 금지문자만 바꾼다).
  이름이 곧 자료의 정체라서, 여기서 손대면 에이전트가 무슨 파일인지 알아보기 어려워진다.

## 학교급 분기 (초 · 중 · 고)

학교알리미는 학교급마다 다른 항목을 공시한다. 그래서 받아 오는 자료도, 만드는 리포트도 셋으로 갈린다.
기준은 `meta.json` 의 `school.kind`(`02` 초 · `03` 중 · `04` 고) 하나다.

실측(2026-09-08, 서울대치초 · 휘문중 · 휘문고 · 학교알리미 공시항목 전수 조회):

| | 초 | 중 | 고 |
|---|---|---|---|
| 공시항목 수 | 41 | 46 | 45 |
| 교과별 학업성취(4-나) | **없음** | 있음 | 있음 |
| 자유학기제(2-마) | 없음 | **있음** | 없음 |
| 전·출입 표(3-나) | 표 있음 | 표 있음 | **표가 비어 있다** (OpenAPI `apiType 10` 으로 받는다) |
| 지역 비교행(구/시도/전국) | 대부분의 표에 붙는다 | 붙는다 | 동아리 정도 |

**초등에 없는 학업 항목은 「교과별 학업성취」 하나뿐이고, 고교 45개 중 40개를 그대로 공유한다.**
자료가 없는 게 아니라 고교 템플릿이 안 쓰던 자료가 초등에 있는 것이다 — 그래서 초등 리포트는
고교를 줄인 문서가 아니라 **다른 질문에 답하는 같은 두께의 문서**로 짰다(설계 근거는
`docs/초중등_리포트_설계개요.md`).

| | 초등 | 중등 | 고등 |
|---|---|---|---|
| 받는 공시 항목 | 17 | 16 | 7 |
| 리포트 분량 | 20쪽 | 20쪽 | 21쪽 |
| 무게중심 | **유입과 유출**(학군 수요) | 성취도 3개년 + 자유학기 | 성취도 3개년 + 대학진학 |
| 만들지 않는 것 | 성취도·석차·등급컷·진학 중학교 | 석차등급·동점자·등급컷·고교 진학처 | — |

없는 항목은 화면에도 띄우지 않는다. 초등학교를 고르면 「교과별 학업성취」 줄이 아예 안 보인다 —
눌러서 404 를 보게 두면 원장은 그걸 고장으로 읽는다.

## 리포트 만들기 (`api/report.js`)

`app.html` 의 **「리포트 만들기」** → 서버가 `claude -p` 를 띄운다 →
`meta.json` 의 `school.kind` 로 **학교급에 맞는 프롬프트**(`분석리포트-생성-초/중/고.md`)를 골라
그 학교급 작업설명서대로 만든다 →
`vault/{학교}_{연도}/out/` 에 PDF 를 넣는다 → 저장소 화면에서 바로 열린다.

- 진행 상황은 `--output-format stream-json` 을 사람이 읽을 줄로 바꿔 화면에 흘린다.
  그냥 `-p` 는 다 끝날 때까지 아무것도 안 뱉어서 몇 분 동안 멈춘 것처럼 보인다.
- **종료코드가 아니라 결과물을 믿는다** — `out/` 에 PDF 가 생겼으면 성공이다.
- 중간 산출물은 `.scratch/{학교}_{연도}/` 에 둔다. 저장소 폴더는 화면에 그대로 보이는 곳이라
  작업 부스러기를 섞지 않는다.
- 실행 명령은 환경변수로 바꾼다: `SR_CLAUDE_BIN`(기본 `claude`), `SR_CLAUDE_ARGS`.
  기본 인자는 `--permission-mode acceptEdits` 에 `Read,Write,Edit,Glob,Grep,Bash` 만 허용이다
  (PDF 변환에 크롬을 부르므로 Bash 가 필요하다).

## 인증키

**따로 넣을 것이 없다.** 학교알리미 OpenAPI 키는 `api/schoolinfo.js` 에 상수로 들어 있다 —
클론해서 `node dev.js` 하면 바로 돈다. 브라우저로는 나가지 않고 서버 함수 안에서만 쓰인다.

키를 갈아끼울 일이 생기면 그 상수를 고치거나, `.env` 에 `SCHOOLINFO_API_KEY` 를 주면 그쪽이 이긴다.

리포트 생성은 **클로드코드 CLI(구독)로만** 돈다. Anthropic API 키를 쓰는 경로는 없다 —
클로드코드가 로그인보다 환경변수를 먼저 보는 성질이 있어서, `api/report.js` 가 자식
프로세스에 넘기기 전에 `ANTHROPIC_*` 값을 지운다. 켜고 끄는 선택지는 두지 않았다.

## 히어로 레이더

장식이 아니라 **입구**다. 훑는 빔이 한 바퀴 돌면서 지나간 자리의 점이 밝아지고 학교 이름표가 뜬다.
점을 누르면 검색창에 다시 칠 필요 없이 그 학교로 바로 조회된다 — 이름표에 쓰는 학교는 전부
`schools.json` 에 실제로 있는 곳이라 클릭이 헛돌지 않는다.

빔 회전과 점 밝기를 CSS 애니메이션 두 개로 따로 돌리면 주기가 조금씩 어긋나 "빔이 지나가지도
않았는데 점이 켜지는" 그림이 나온다. 그래서 각도를 `requestAnimationFrame` 에서 한 번만 계산해
빔 회전(`transform`)과 점 밝기(`--lit`)에 같이 먹인다. `prefers-reduced-motion` 이면 빔을 멈추고
이름표를 계속 띄워 둔다 — 눌러서 조회하는 기능은 그대로 남는다.

## 페이지 셋 · 접속 코드

| 파일 | 화면 |
|---|---|
| `index.html` | **랜딩** — 히어로가 한 화면(`100dvh`)을 다 쓴다. 레이더 + 접속 코드 |
| `app.html` | **도구** — 상단 막대 + 학교 검색 · 공시 원문 파일 · 결과 표 · 리포트 만들기 |
| `vault.html` | **저장소** — 받아 둔 자료와 만들어진 리포트를 폴더 그대로 |

**서로 다른 문서다.** 한 파일에서 숨겼다 보였다 하는 게 아니라 진짜로 페이지를 옮긴다 —
코드가 맞으면 `location.href = 'app.html'`, 「나가기」와 브랜드는 `index.html` 로 가는 평범한 링크다.
그래서 라우터도, 서버 리라이트도 필요 없다. 뒤로가기는 브라우저가 알아서 한다.

나눠 놓으니 랜딩이 가볍다 — 도구 쪽 코드도 `schools.json`(1.9MB)도 받지 않는다.
레이더 이름표는 랜딩 안의 `POOL` 목록으로 돌고, 점을 누르면
`app.html?school=휘문고등학교` 로 넘겨 도구 쪽에서 색인을 받은 뒤 그 학교를 바로 고른다.

`app.html` 은 열리자마자 통과 여부를 보고 아니면 `location.replace('index.html')` 로 되돌린다
(히스토리에 남기지 않는다). 이미 통과한 브라우저가 랜딩에 오면 코드칸이 사라지고
「들어가기」만 남는다.

코드 값은 `public/gate.js` 한 곳에 있다(현재 `'1234'`). 두 페이지가 같은 파일을 읽으므로
값이 어긋날 일이 없고, **코드를 바꾸면 저장값이 달라져 모두에게 다시 묻는다** — 따로 초기화할 필요가 없다.

> ⚠️ **이건 잠금이 아니라 문턱이다.** 확인이 브라우저 안에서만 일어나므로 `gate.js` 를 열면
> 코드가 그대로 보이고, `app.html` 을 직접 열어 되돌리기 전에 멈추면 화면은 열린다.
> `schools.json` · `kess.json` 도 주소만 알면 그냥 받아진다.
> 링크를 받은 사람이 바로 쓰게 하는 용도로는 충분하지만, 정말 막아야 한다면 서버(`api/`)에서
> 확인하고 **도구와 데이터를 그때 내려 주는** 구조로 바꿔야 한다.
>
> 이 저장소가 공개라 코드 값도 공개다. 지금은 로컬 전용 도구라 실질적인 문제가 없지만,
> 배포해서 쓰기로 하면 **먼저 이 값을 바꾸고 서버 확인으로 옮긴 다음** 올려야 한다.

## 공시 원문 파일 (`api/gongsi.js`)

OpenAPI 가 주지 않는 자료는 학교알리미 공시 화면에만 있어서, 사이트가 쓰는 것과 같은 방식으로 받아 온다.

**표로 공시된 항목**(`TABLE_ACTS`)은 전부 같은 경로를 탄다 — 화면의 표 HTML 을 `ExcelPrint.do` 에
되돌려 보내면 사이트 ‘엑셀저장’과 같은 `.xls` 가 나온다. 항목을 늘리려면 그 표에 한 줄 더하면 된다.

| `act` | 받는 것 | 쓰는 학교급 |
|---|---|---|
| `club` | 동아리 활동 현황 | 초·중·고 |
| `move` | 전·출입 및 학업중단 (구/시도/전국 비교행 포함) | 초·중 — **고교는 표가 비어 있다** |
| `enter` | 입학생 현황 (초등은 적령·조기·유예) | 초·중 |
| `paps` | 학생의 체력 증진 — 학년·성별 1~5등급 분포 | 초·중 |
| `hours` | 수업일수 및 수업시수 | 초·중 |
| `roster` | 학년별·학급별 학생수 (반별 전수) | 초·중 |
| `special` | 교육운영 특색사업 | 초·중·고 |
| `freesem` | 자유학기제 운영 | **중학교만** |
| `library` · `counsel` · `meal` | 도서관 · 상담 · 급식 (전부 지역비교 포함) | 초등 |

**첨부 원본**은 항목 아래 붙은 파일을 그대로 내려받는다.

| `act` | 받는 것 | 방식 |
|---|---|---|
| `rule` | 학업성적관리규정 | ‘교과별(학년별) 교수ㆍ학습 및 평가계획’ 첨부 중 이름이 맞는 것. 초등은 ‘학업 성적 관리 규정’ 처럼 띄어 쓰는 학교가 있어 후보를 넓게 잡는다 |
| `curriculum` | 학교교육과정 편성·운영 및 평가 | 고·중은 편제표, **초등은 학교교육계획 책자**(수백 쪽 PDF)다. 같은 자리에 연간학사일정이 붙어 있어 ‘교육과정’ 쪽만 고른다 |
| `evalplan` | 교과별 교수·학습 및 평가계획 | 첨부가 여러 개다 — **초등은 학년별로 쪼개져 있다**(1~6학년 6개). `idx` 없이 부르면 목록, `idx=N` 이면 그 파일 |
| `achieve-start` → `achieve-solve` | 교과별 학업성취 `.xls` | 이 항목에만 숫자 확인 절차가 있다. 그 화면을 **그대로 사용자에게 띄우고**, 사람이 읽은 값을 받아 넘긴다. **초등에는 항목 자체가 없다** |

화면에서는 학교급에 맞는 항목을 **체크박스 목록 + 「선택한 파일 받기」 버튼 하나**로 묶어 받는다
(기본 전부 체크). 동시에 쏘지 않고 **순서대로** 하나씩 부른다 — 항목마다 상세페이지를 새로 열고
세션 쿠키를 잡는 구조라 같은 순간 여러 세션이 붙으면 사이트 쪽에서 엉킨다. 한 항목이 실패해도
나머지는 계속 가고, 실패 사유는 그 줄 오른쪽에 남는다(학교·연도에 따라 없는 항목이 있다).
`achieve` 는 숫자 확인 절차 때문에 사람 손이 필요해 중간에 창을 띄우고 기다린다.

사이트가 EUC-KR + 세션 쿠키 + CORS 미허용이라 브라우저가 직접 부를 수 없다.
한글 파라미터를 EUC-KR 로 인코딩해야 해서 `iconv-lite` 하나만 의존성으로 쓴다.

서버리스는 요청 사이에 상태가 없다. 그래서 숫자 확인 2단계는 세션 쿠키·폼필드를
클라이언트에 잠깐 맡겼다가 되돌려받는다. 공개 사이트의 임시값이라 비밀은 아니지만,
되돌아온 값을 그대로 믿지 않도록 요청 경로를 공시 프래그먼트 패턴으로 제한한다.

## 졸업생 진로 · 학교 규모 (`build-kess.js` → `public/kess*.json`)

리포트 08절이 쓰는 **진학·재수 숫자는 학교알리미에도 NEIS 개방포털에도 없다.** NEIS 가 주는 12종은
학교 기본정보·급식·학사일정·시간표·학과계열·학원교습소뿐이라 학생수조차 없다. 원천은 **교육기본통계**
(교육부 조사 · 한국교육개발원 수행, 매년 4/1 기준)이고, 공표 창구는 **KESS** 한 곳이다.

KESS 는 API 를 주지 않는다 — 전국 한 파일(20,660행 × 149열, 18MB)을 통째로 내려받는 방식뿐이라
서버리스 함수로는 다룰 수 없다. 그래서 `schools.json` 과 같은 방식으로 미리 훑어 둔다.

```bash
node build-kess.js            # 학교급별로 자동 판별
node build-kess.js 2025 2024 2023
```

같은 파일에 **초 6,369 · 중 3,313 · 고 2,391** 행이 함께 들어 있다. 셋을 각각 뽑아 나눠 쓴다 —
합치면 첫 로딩이 무거워진다(고교 색인만도 757KB).

| 파일 | 학교급 | 담는 것 | 크기 |
|---|---|---|---|
| `public/kess.json` | 고등학교 2,451개 · 3개년 | 진학처까지 전부 | 757KB |
| `public/kess-ms.json` | 중학교 3,365개 · 3개년 | 졸업자·진학자·**진학률까지** | 781KB |
| `public/kess-es.json` | 초등학교 6,499개 · **4개년** | 학년별(1~6) 학생수·학급수·전출입·입학자 | 1.7MB |

학교급마다 있는 열이 다르다. **초등은 졸업·진학이 조사 대상이 아니라 그 칸이 통째로 0 이다** —
넣어 두면 화면이 0 을 '진학자 없음' 으로 읽으므로 색인 단계에서 아예 뺀다.
**중학교는 진학률까지만이고 진학처 분류(일반고·특목고·특성화고)는 고등학교 행에만 채워진다** —
중등 리포트에 고교 진학 분포 절을 넣을 수 없는 이유다.

연도 선별 기준도 학교급마다 다르다. 중·고는 '진학 칸이 찼는가'로 보지만, 초등은 그 칸이 영원히
비어 있어서 그 기준을 쓰면 한 해도 못 고른다 — 초등은 '학생수가 찼는가'로 본다.
초등만 4개년인 것도 같은 이유다(선공개분에 걸릴 일이 없고, 신입생 추세는 3개년으로는 방향이 안 보인다).

**최신 파일을 그냥 믿으면 안 된다.** 상반기 파일은 4/1 조사분이라 ‘졸업 후 상황’ 칸이 비어 있는 채로
먼저 올라온다 — 2026년 파일은 졸업자만 있고 진학·기타가 전부 0 이다. 그래서 연도를 안 주면 최신부터
내려가며 **진학 칸이 실제로 찬 해만** 3개 고른다(기재율 50% 미만이면 선공개분으로 보고 건너뛴다).
서버 파일명(`downLoad('id','2026162291710.xlsx',…)`)은 갱신될 때마다 바뀌므로 목록 페이지에서 매번 긁는다.

화면에서는 **고등학교를 골랐을 때만** ‘졸업생 진로 · 학교 규모 추이’ 항목이 뜨고, 「선택한 파일 받기」에 함께 묶인다.
서버를 타지 않으므로 즉시 끝난다. 내려가는 `.csv` 는 네 부분이다:

| | 내용 | 쓰는 곳 |
|---|---|---|
| `[1]` | 대상 학교 3개년 — 졸업자·진학·진학률·국내대학/전문대/국외·취업·입대·기타·**기타율** + 검산 | 08절 페이지 A |
| `[2]` | 같은 구 고교 전체 (졸업자 순, 유형 표기) — 비교군 4~5곳을 여기서 고른다 | 08절 페이지 B |
| `[3]` | 기타율 낙차 — 학교 → 구 → 시도 → 전국 (일반고+자율고만 합산) | 08절 페이지 B |
| `[4]` | 학교 규모·교원 3개년 — 학년별 학생수·학급수·학급당 학생수·교원(기간제 포함)·교원1인당·전출입·**순전입**·입학자 + 구 학교당 평균 | 03절 모수 |

`[4]` 는 학교알리미도 주는 항목이지만 거긴 당해연도 한 장뿐이라 **추세가 안 보인다.**
같은 파일 149열 안에 이미 들어 있어 함께 뽑아 둔다(전체 22열). 조사 시점이 달라서 —
학생수·교원은 **4/1 조사 시점**, 졸업 후 상황(`[1]`)만 **직전 2월 졸업생** 기준 — 표에 그렇게 적는다.
비율 열(진학률·학급당 학생수·교원1인당 학생수)은 집계할 때 더하지 않고 합계에서 다시 나눈다.

취업·입대가 0 에 가까우면 **기타 ≈ N수(재수) 규모**로 읽는다 — 리포트의 중심 지표다.
진학률 칸이 0 이면 미기재이므로 진학자÷졸업자로 다시 나누고 `(재계산치)` 라고 밝힌다.
검산(진학+취업+입대+기타 = 졸업자)이 어긋나면 그 줄에 그대로 적는다.

특목·특성화고는 집계에서 뺀다. 진로 구조가 아예 달라 섞으면 일반고 재수율이 왜곡된다.
(`[2]` 목록에는 유형을 붙여 그대로 보여 준다 — 같은 구에 뭐가 있는지는 알아야 하기 때문)

`exceljs` 는 이 색인을 만들 때만 쓰는 개발 의존성이다. 배포되는 함수는 여전히 `iconv-lite` 하나만 쓴다.
`.kess-cache/` 에 원본 xlsx 가 남는데(연도당 18MB) 지워도 되고, git·배포에서는 빠진다.

프롬프트 둘이 있다.

| 파일 | 하는 일 |
|---|---|
| `prompts/학교분석-자료수집.md` | 학교 이름을 묻고 위 자료를 전부 받는다. 숫자 확인은 이미지를 띄워 물어본다 |
| `prompts/분석리포트-생성-초.md` | 초등학교용 — 20쪽. 성적이 없는 대신 유입·평가계획·체력·돌봄이 축이다 |
| `prompts/분석리포트-생성-중.md` | 중학교용 — 20쪽. 성취도는 있고 석차등급·동점자·등급컷은 제도적으로 없다 |
| `prompts/분석리포트-생성-고.md` | 고등학교용 — 21쪽. 기존 리포트 그대로 |

「리포트 만들기」 버튼은 `meta.json` 의 `school.kind`(02·03·04)를 보고 셋 중 하나를 고른다.
각 프롬프트는 `docs/분석리포트_작업설명서.md` 의 공통 규칙(§0·§4·§8·§9)과 학교급 절 지도
(`_초.md`·`_중.md`, 고교는 같은 문서의 §2·§3)를 규칙서로, `docs/template/분석리포트_템플릿_정본{_초|_중}.htm`
을 틀의 정본으로 삼는다 — 무인 실행이라 물어볼 수 없으므로, 자료가 모자란 절은 만들지 않고
`out/제작메모.md` 에 무엇이 왜 빠졌는지 적는다. **빈 표나 지어낸 숫자로 쪽을 채우지 않는다.**

## 왜 색인을 따로 만드나

공시 목록 API(`apiType=0`)는 **시도·시군구 단위로만** 응답한다. 그래서 화면에서
지역을 고르게 하지 않으려면 전국을 미리 훑어 한 파일로 만들어 둬야 한다.
`build-schools.js` 가 (시도 × 시군구 × 학교급) 768 조합을 돌며 모아
`public/schools.json` 을 만든다(약 3분, gzip 265KB).

```bash
node build-schools.js 2026
```

색인 한 행에 **시도·시군구·학교급 코드**가 함께 들어 있어서, 학교를 고르는 순간
공시 항목 조회에 필요한 파라미터가 전부 갖춰진다. 학교명 검색은 공백 무시 + 초성
(`ㅎㅁㄱ` → 휘문고등학교)까지 받는다.

## 왜 서버리스 함수가 필요한가

학교알리미(schoolinfo.go.kr)는 응답에 `Access-Control-Allow-Origin` 헤더를 주지 않는다.
그래서 브라우저가 직접 부르면 **요청은 나가고 서버도 200 으로 답하지만 브라우저가 응답을
JS 에 넘겨주지 않는다.** 실제 크롬으로 확인한 결과:

```
[fetch]   FAILED -> Failed to fetch
[xhr]     FAILED (status=0)
[no-cors] body length = 0 (opaque)
```

코드로 우회할 수 없고 JSONP 도 지원하지 않는다. `api/schoolinfo.js` 가 브라우저 대신
호출해 주며, 프론트와 같은 도메인이라 동일 출처가 되어 CORS 자체가 성립하지 않는다.

## 배포하지 않는다

`.vercel/` 링크와 `vercel.json` 은 남아 있지만 지금 구조에서는 쓰지 않는다 —
이유는 위 「로컬 전용이다」. 조회 전용으로 되돌려 배포하고 싶으면 `api/vault.js` ·
`api/report.js` 를 빼고 `public/app.html` 의 저장소 호출을 다운로드로 되돌리면 된다.

## 실행

```bash
node dev.js       # http://localhost:3000  ·  저장소는 vault/
```

`.env` 를 먼저 읽고, `public/` 을 서빙하고, `api/*` 를 붙이고, `/vault/…` 로 저장소 파일을
내려 준다. PDF 는 `Content-Disposition: inline` 이라 저장소 화면의 미리보기에서 바로 열린다.

## 호출량

공시 데이터는 연 단위로만 바뀌므로 응답에 `s-maxage=1800` 을 걸어 CDN 에서 30분 캐시한다.
원장 여러 명이 같은 지역을 열어도 학교알리미로 나가는 실제 호출은 사실상 한 번이다.
